# Usage

## Claude Code

Use the prompt in `SKILL.md` or add the skill directory to the workspace's `.claude/skills` path.

## Gemini

Gemini does not natively discover Claude skills. Use the prompt from `SKILL.md` or `GEMINI_PROMPT.md` directly in the chat box, or copy it into a custom command.

## Codex

Use the same prompt text in Codex. The skill is designed to be backend-agnostic and prompt-driven.
