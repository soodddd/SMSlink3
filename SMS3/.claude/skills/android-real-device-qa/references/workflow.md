# Workflow

1. Load the requirements or technical document.
2. Derive a scenario matrix from the document.
3. Detect connected devices and choose target serials.
4. Build the app.
5. Install the app on the target device(s).
6. Run preflight and permission gates.
7. Execute the scenario matrix.
8. Capture evidence after every failure.
9. Classify the failure.
10. Patch only confirmed product defects.
11. Rebuild, reinstall, and rerun the exact failed case.
12. Repeat until all in-scope scenarios pass or the remaining blockers are non-product.
