# Changelog

## 2026-09-06 — Reliability and security hardening

本轮对 SMSlink3 的设备连接、配对、安全、短信、通知、通话、文件传输和诊断链路进行了系统性修复。详细验证数据见 [`VALIDATION_REPORT_2026-09-06.md`](VALIDATION_REPORT_2026-09-06.md)。

### Added

- 按设备保存通知同步回执，并用通知内容指纹识别更新。
- BLE 分片编解码、文件包编解码、应用层帧长度限制和配对令牌存储。
- 诊断日志存储、设置/诊断 ViewModel、拨号入口和二维码辅助组件。
- Room 数据库迁移和文件断点续传检查点。

### Fixed

- 设备删除时同步撤销连接、令牌和证书，避免残留信任关系。
- 连接重试、监听器自恢复、链路切换和旧连接覆盖新连接的问题。
- TCP/RFCOMM 并发写入、部分帧读取、超时重试和资源关闭问题。
- BLE GATT 操作并发、回调归属、分片长度、偏移读取和服务端注册时序问题。
- 配对二维码、BLE/UDP 发现包的身份、时间戳、设备类型和输入长度校验。
- 短信目标设备校验、发送结果 ACK、多段短信 PendingIntent、分段状态聚合和系统短信回读匹配。
- 通知目标设备回执、内容更新、删除传播、重复事件重试和新设备补同步。
- 文件传输的大小、哈希、路径、顺序、断点、ACK、失败清理和接收会话生命周期。
- 通话控制的通话 ID、电话号码、状态校验、回执、取消和服务实例生命周期。
- TLS 证书精确匹配、证书链校验、有效期校验和身份密钥存储。
- 异常时间戳导致的 `Long` 溢出匹配，以及文件校验失败后的残留会话。
