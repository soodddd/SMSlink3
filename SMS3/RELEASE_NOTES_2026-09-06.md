# SMSlink3 更新说明 — 2026-09-06

## 本次更新

这是一次面向可靠性、安全性和可验证性的重构更新，重点覆盖 Android 设备之间的发现、配对、连接、消息同步和文件传输。

## 用户可见改进

1. 设备断线后会按设备和链路策略恢复连接，旧连接不会覆盖新连接。
2. 多段短信只有在分段回执完成后才显示最终发送状态。
3. 通知内容发生更新时，会重新发送给尚未收到新内容的设备。
4. 新设备连接后可以按设备回执补同步最近通知和短信。
5. 文件传输增加明确接受、逐块 ACK、哈希校验、断点续传和失败清理。
6. 配对和网络消息增加身份、目标设备、时间戳、长度和证书校验。
7. 设置页和诊断页提供权限、连接策略和诊断日志入口。

## 安装与升级

- 目标系统：Android 13+。
- 两台设备应安装同一版本 APK。
- 升级后需要重新确认短信、电话、蓝牙、通知监听和必要的系统角色权限。
- 数据库已提供迁移；如果使用非常早期的开发版本，首次启动可能需要重新配对。
- 当前产物是 Debug APK，仅用于测试，不是发布签名包。

## 已知边界

本地测试和 APK 构建不能替代真实设备验收。以下项目仍需在两台目标 Android 设备上实际验证：

- 二维码配对、BLE GATT、RFCOMM 回退。
- 局域网/热点连接、断网恢复和链路切换。
- 真实 SIM 的单段/多段短信及运营商回执。
- 通知监听权限、通知镜像和交互回传。
- 默认电话应用、Telecom/InCallService 和通话控制。
- 大文件、暂停/恢复、杀进程后的断点续传。
